# Settlem Academy — Deploy Now

## Easiest path: Render

This project now includes `render.yaml`.

### 1. Put the project in GitHub
Create a GitHub repository and upload the contents of this folder.

### 2. Create the Render service
In Render, create a Blueprint from the repository. Render will read `render.yaml`.

### 3. Add these environment values
- `FRONTEND_ORIGIN` = your final website URL
- `ADMIN_NAME` = your admin name
- `ADMIN_EMAIL` = your admin email
- `ADMIN_PASSWORD` = a strong password

`JWT_SECRET` is generated by Render.

### 4. First admin
After deployment, the admin account must be provisioned with:
`npm run seed:admin`

If using Render Shell:
```bash
npm run seed:admin
```

### 5. Test
Open:
- `/api/health`
- `/admin-login.html`
- `/student-login.html`

### 6. Custom domain
After the service is working, add your domain in the hosting provider and enable HTTPS.

## Important SQLite note
This deployment uses the existing SQLite backend with a persistent disk. That is suitable for an initial single-instance launch. Before scaling to multiple server instances, migrate the database to managed PostgreSQL.

## Production hardening still recommended
HTTPS, rate limiting, password reset, email verification, backups, audit logging, monitoring, and PostgreSQL migration before significant scale.
