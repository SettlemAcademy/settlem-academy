12-Lesson Study Guide

Lesson 1Probability Basics & Terminology

Learning Objective: Understand random experiments, sample space, events, favourable outcomes and basic probability.

Core Concepts

  • Random experiment: an experiment whose outcome cannot be predicted with certainty.
  • Sample space S: the set of all possible outcomes.
  • Event A: a subset of the sample space.
  • Favourable outcomes: outcomes belonging to the event being considered.

Must-Know Formulas

P(A) = Number of favourable outcomes / Total number of equally likely outcomes
0 ≤ P(A) ≤ 1
P(S) = 1
P(∅) = 0
P(Aᶜ) = 1 − P(A)

Worked Examples

A fair die is thrown once. Probability of an even number = 3/6 = 1/2.

Two coins are tossed. S = {HH, HT, TH, TT}; probability of exactly one head = 2/4 = 1/2.

Exam Practice

  1. Write the sample space for three coin tosses.
  2. A die is thrown once. Find P(number > 4).
  3. A card is drawn from a standard deck. Find P(Ace).

Teaching Focus

Start with a simple question: when we toss a coin, can we know the exact result before tossing? No. That is a random experiment. First list every possible outcome; that list is the sample space. Then identify the outcomes we want. Probability is favourable outcomes divided by total equally likely outcomes. Always write the sample space before calculating.

Lesson 2Conditional Probability & Bayes’ Theorem

Learning Objective: Calculate conditional probabilities and solve Bayes-type problems.

Core Concepts

  • Conditional probability measures the chance of A when B is already known to have occurred.
  • Independent events satisfy P(A∩B)=P(A)P(B).
  • Bayes’ theorem reverses conditional probability using prior probabilities.

Must-Know Formulas

P(A|B) = P(A∩B)/P(B), P(B)>0
P(A∩B) = P(A|B)P(B)
P(A|B) = P(B|A)P(A)/P(B)
P(A) = Σ P(A|Bᵢ)P(Bᵢ) for a partition {Bᵢ}

Worked Examples

If P(A∩B)=0.2 and P(B)=0.5, then P(A|B)=0.4.

A factory has two machines producing 60% and 40% of items, with defect rates 2% and 5%. Bayes’ theorem can find the probability a defective item came from the second machine.

Exam Practice

  1. Given P(A)=0.6, P(B)=0.5 and P(A∩B)=0.3, test independence.
  2. Solve a two-machine defective-item problem using Bayes’ theorem.
  3. Explain the difference between P(A|B) and P(B|A).

Teaching Focus

The key idea is that conditional probability changes the reference set. If B has already happened, we are no longer looking at the whole sample space; we focus on B. Then Bayes’ theorem lets us work backwards from an observed result to the likely cause.

Lesson 3Random Variables — Concept & Types

Learning Objective: Understand random variables and distinguish discrete and continuous variables.

Core Concepts

  • A random variable X assigns a numerical value to each outcome of a random experiment.
  • Discrete random variables take countable values such as 0,1,2,…
  • Continuous random variables can take values over intervals such as time, height or temperature.

Must-Know Formulas

For a discrete X: P(X=x) = p(x)
For a continuous X: P(a≤X≤b) = ∫ₐᵇ f(x)dx

Worked Examples

Number of heads in three coin tosses is discrete.

Waiting time for a bus is modelled as continuous.

Exam Practice

  1. Define a random variable with one suitable example.
  2. Classify number of students absent in a class as discrete or continuous.
  3. Give two examples of continuous random variables.

Teaching Focus

A random variable is not a variable that is randomly changing in an informal sense. It is a mathematical rule that converts outcomes into numbers. The most important classification is discrete versus continuous. Remember: counting usually gives discrete values; measurement usually gives continuous values.

Lesson 4Probability Mass Function (PMF)

Learning Objective: Construct, verify and use a PMF for a discrete random variable.

Core Concepts

  • PMF is p(x)=P(X=x).
  • Every probability must be non-negative.
  • The sum of all PMF values must equal one.

Must-Know Formulas

p(x) ≥ 0
Σ p(x) = 1
P(a≤X≤b) = Σ p(x) over the required values

Worked Examples

For X = number of heads in two fair coin tosses: p(0)=1/4, p(1)=1/2, p(2)=1/4.

Exam Practice

  1. Check whether a proposed table is a valid PMF.
  2. Find an unknown constant k so that p(x)=kx for x=1,2,3 is a PMF.
  3. Find P(X≥2) from a given PMF.

Teaching Focus

For a PMF, think of a probability table. The two checks are simple: no probability can be negative, and all probabilities together must add to one. Once the PMF is valid, probabilities of events are obtained by adding the required entries.

Lesson 5Probability Density Function (PDF)

Learning Objective: Understand PDFs and calculate probabilities using integration.

Core Concepts

  • A PDF f(x) describes a continuous random variable.
  • Probability is area under the density curve.
  • The probability at one exact point is zero for a continuous variable.

Must-Know Formulas

f(x) ≥ 0
∫₋∞^∞ f(x)dx = 1
P(a≤X≤b)=∫ₐᵇ f(x)dx

Worked Examples

If f(x)=2x for 0<x<1, then P(0.2<X<0.6)=∫₀.₂⁰.₆2x dx = 0.32.

Exam Practice

  1. Find k so that f(x)=kx on 0<x<2 is a valid PDF.
  2. Find P(X>1) for a given PDF.
  3. Verify that a density integrates to one.

Teaching Focus

For a continuous random variable, probabilities are areas, not individual table entries. The total area under the PDF must be one. To find the probability between two values, integrate the density between those limits.

Lesson 6Mathematical Expectation

Learning Objective: Calculate mean or expected value for discrete and continuous random variables.

Core Concepts

  • Expectation is the long-run weighted average of a random variable.
  • For a discrete variable, multiply each value by its probability and add.
  • For a continuous variable, integrate x times the PDF.

Must-Know Formulas

E[X] = Σ xp(x)
E[g(X)] = Σ g(x)p(x)
E[X] = ∫ x f(x)dx for continuous X
E[aX+b] = aE[X]+b

Worked Examples

If X takes 0,1,2 with probabilities 1/4,1/2,1/4, then E[X]=0(1/4)+1(1/2)+2(1/4)=1.

Exam Practice

  1. Find E[X] from a PMF.
  2. Find E[X²] from a PMF.
  3. Use linearity of expectation to find E[3X+5].

Teaching Focus

Expectation is a weighted average. Values that have larger probabilities contribute more strongly. For a discrete variable use summation; for a continuous variable use integration. One very useful property is linearity: constants can be handled directly without finding a new distribution.

Lesson 7Variance & Standard Deviation

Learning Objective: Calculate variance and standard deviation and interpret spread.

Core Concepts

  • Variance measures how far values spread around the mean.
  • Standard deviation is the positive square root of variance.

Must-Know Formulas

Var(X)=E[X²]−(E[X])²
σ=√Var(X)
Var(aX+b)=a²Var(X)

Worked Examples

If E[X]=3 and E[X²]=11, Var(X)=11−9=2 and σ=√2.

Exam Practice

  1. Find variance from a PMF.
  2. Given E[X] and E[X²], calculate standard deviation.
  3. If Var(X)=4, find Var(3X+2).

Teaching Focus

Mean tells us the centre; variance tells us the spread. In exam problems the fastest route is often Var(X)=E[X²]−[E(X)]². Remember that adding a constant does not change variance, while multiplying X by a changes variance by a².

Lesson 8Bernoulli & Binomial Distribution

Learning Objective: Recognize Bernoulli trials and solve binomial probability problems.

Core Concepts

  • A Bernoulli trial has exactly two outcomes: success and failure.
  • Binomial distribution counts the number of successes in n independent Bernoulli trials with constant success probability p.

Must-Know Formulas

Bernoulli: P(X=1)=p, P(X=0)=q=1−p
Binomial: P(X=r)=C(n,r)pʳqⁿ⁻ʳ
E[X]=np
Var(X)=npq

Worked Examples

For n=5 and p=0.4, P(X=2)=C(5,2)(0.4)²(0.6)³ = 0.3456.

Exam Practice

  1. Find the probability of exactly r successes.
  2. Find the probability of at least one success.
  3. Calculate mean and variance of a binomial distribution.

Teaching Focus

First check the conditions: fixed number of trials, two outcomes, independent trials and constant p. If all four are present, binomial distribution is usually the correct model. Use the combination term because we only care about how many successes occur, not their order.

Lesson 9Poisson Distribution

Learning Objective: Solve Poisson probability questions and identify when the model is useful.

Core Concepts

  • Poisson distribution models counts of events in a fixed interval when events occur independently at an average rate.
  • It is often used for arrivals, defects, calls or occurrences.

Must-Know Formulas

P(X=r)=e⁻λ λʳ/r!
E[X]=λ
Var(X)=λ

Worked Examples

If the average number of calls per minute is 2, the probability of exactly 3 calls is e⁻² 2³/3!.

Exam Practice

  1. Find P(X=0), P(X=1) or P(X=r).
  2. Given the mean, identify λ.
  3. Use Poisson approximation to a binomial when appropriate.

Teaching Focus

In Poisson problems, lambda is the average number of occurrences in the chosen interval. The most important memory point is that mean equals variance equals lambda. Be careful that lambda must match the interval used in the question.

Lesson 10Continuous Probability Distributions

Learning Objective: Work confidently with support intervals, PDFs, CDFs and continuous probabilities.

Core Concepts

  • Support is the interval where the density is non-zero.
  • CDF F(x)=P(X≤x).
  • For a continuous variable, P(X=x)=0.

Must-Know Formulas

F(x)=∫₋∞ˣ f(t)dt
P(a<X≤b)=F(b)−F(a)
f(x)=F'(x) where differentiable

Worked Examples

If X is uniform on (0,1), f(x)=1 and F(x)=x for 0<x<1.

Exam Practice

  1. Find the CDF from a PDF.
  2. Find a probability using the CDF.
  3. Find a PDF by differentiating a CDF.

Teaching Focus

The CDF collects probability from the far left up to x. This makes probability differences easy: F(b)-F(a). Learn to move in both directions—PDF to CDF by integration, and CDF to PDF by differentiation.

Lesson 11Important Exam Problems — Part 1

Learning Objective: Apply probability, conditional probability, PMF, expectation and variance concepts in exam-style problems.

Core Concepts

  • Focus on identifying the correct theorem or formula before calculating.
  • Show the distribution or sample space clearly to earn method marks.

Must-Know Formulas

P(A∪B)=P(A)+P(B)−P(A∩B)
P(A|B)=P(A∩B)/P(B)
E[X]=Σxp(x)
Var(X)=E[X²]−[E(X)]²

Worked Examples

Construct the PMF for number of heads in three fair coin tosses and calculate its mean and variance.

Solve a Bayes problem involving two suppliers with different defect rates.

Exam Practice

  1. Three coins are tossed. Find the distribution, mean and variance of the number of heads.
  2. A PMF contains an unknown constant k. Find k and then calculate E[X].
  3. Two events have known probabilities and intersection. Find conditional probabilities.

Teaching Focus

This lesson is about exam method. Read the question, identify the random variable, write the known information, choose the formula, substitute carefully and state the final answer clearly. Do not jump straight into arithmetic.

Lesson 12Important Exam Problems — Part 2 + Revision

Learning Objective: Consolidate distributions, PDFs, moments and common exam traps.

Core Concepts

  • Compare binomial and Poisson models.
  • Review PMF versus PDF.
  • Review mean, second moment, variance and standard deviation.
  • Check support and normalization before calculating probabilities.

Must-Know Formulas

Binomial: P(X=r)=C(n,r)pʳqⁿ⁻ʳ
Poisson: P(X=r)=e⁻λ λʳ/r!
Var(X)=E[X²]−[E(X)]²
P(a<X≤b)=F(b)−F(a)

Worked Examples

A binomial problem with large n and small p may be approximated by Poisson with λ=np when the approximation conditions are suitable.

Given E[X]=4 and Var(X)=3, E[X²]=Var(X)+[E(X)]²=19.

Exam Practice

  1. Choose between binomial and Poisson for three short scenarios.
  2. Find E[X²] from mean and variance.
  3. Solve a PDF normalization and probability problem.
  4. Complete a 20-question timed revision test.

Teaching Focus

Use this final lesson as a checklist. Can you identify a random variable? Can you decide discrete or continuous? Can you validate a PMF or PDF? Can you calculate expectation and variance? Can you choose binomial or Poisson? If yes, you are ready for the practice test.
